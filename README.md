<section>
    <h2>📌 Descripción del proyecto</h2>
    <p>
        Este proyecto presenta un <strong>análisis de datos end-to-end</strong> sobre ventas de un e-commerce,
        utilizando un <strong>dataset real de Kaggle (Online Retail Dataset)</strong> con más de
        <strong>540.000 transacciones</strong>.
    </p>
    <p>
        El objetivo es extraer <strong>insights de negocio</strong> a partir de datos reales, aplicando limpieza,
        análisis exploratorio y visualización, simulando un escenario laboral real para un
        <strong>Data Analyst Junior</strong>.
    </p>
</section>

<section>
    <h2>🎯 Objetivos del análisis</h2>
    <ul>
        <li>Analizar la evolución de las ventas a lo largo del tiempo</li>
        <li>Identificar productos y clientes más relevantes</li>
        <li>Calcular métricas clave del negocio (KPIs)</li>
        <li>Apoyar la toma de decisiones mediante visualizaciones claras</li>
    </ul>
</section>

<section>
    <h2>🧰 Herramientas utilizadas</h2>
    <ul>
        <li><strong>Python</strong> (pandas, matplotlib)</li>
        <li><strong>Excel</strong> (análisis exploratorio y validaciones)</li>
        <li><strong>Power BI</strong> (dashboard interactivo)</li>
    </ul>
</section>

<section>
    <h2>🧹 Limpieza y preparación de datos</h2>
    <ul>
        <li>Conversión de fechas a formato <code>datetime</code></li>
        <li>Tratamiento de valores nulos (CustomerID, Description)</li>
        <li>Eliminación de registros con cantidades o precios negativos</li>
        <li>Creación de métricas derivadas</li>
    </ul>
    <p>
        <code>Total de Venta = Quantity × UnitPrice</code>
    </p>
</section>

<section>
    <h2>📈 KPIs principales</h2>
    <ul>
        <li>💰 <strong>Total de ventas:</strong> $2,498,803.97</li>
        <li>🧾 <strong>Transacciones:</strong> 541,909</li>
        <li>👥 <strong>Clientes únicos:</strong> 4,372</li>
        <li>📦 <strong>Productos únicos:</strong> 4,223</li>
    </ul>
</section>

<section>
    <h2>📊 Visualizaciones</h2>
    <ul>
        <li>Evolución de ventas por mes</li>
        <li>Top 10 productos más vendidos</li>
        <li>Top 10 clientes más frecuentes</li>
    </ul>
    <p>
        Las visualizaciones fueron desarrolladas en <strong>Power BI</strong> para facilitar el análisis interactivo.
    </p>
</section>

<section>
    <h2>🧠 Insights destacados</h2>
    <ul>
        <li>Un pequeño grupo de productos concentra una gran parte de las ventas</li>
        <li>Se detecta estacionalidad en determinados meses</li>
        <li>Clientes recurrentes generan un alto volumen de ingresos</li>
    </ul>
</section>

<section>
    <h2>💡 Recomendaciones de negocio</h2>
    <ul>
        <li>Priorizar stock y campañas en productos más vendidos</li>
        <li>Implementar estrategias de fidelización de clientes</li>
        <li>Planificar promociones según estacionalidad</li>
    </ul>
</section>
